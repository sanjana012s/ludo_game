
# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) (or [oxc](https://oxc.rs) when used in [rolldown-vite](https://vite.dev/guide/rolldown)) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## 🌟 **Overview**
Welcome to **Dice Dare Ludo**, an exhilarating multiplayer game built with **React** and **Vite**! This isn't your ordinary Ludo game – it's a thrilling blend of luck, strategy, and hilarious dares. Gather your friends (up to 4 players) and compete to be the first to roll **three sixes** on the dice. But beware, rolling a six triggers exciting challenges and tasks that will keep everyone laughing!

## 🎯 **Features**
- **👥 Multiplayer Madness**: Supports 4 players with customizable names.
- **🎲 Dice Rolling**: Realistic dice rolls (1-6) with instant results.
- **⭐ Six Counter**: Track how many sixes each player has rolled.
- **🎉 Dare Challenges**: Roll a six? Click "Congratulations!" to unlock fun tasks like singing, dancing, or silly walks!
- **🏆 Winner Announcement**: The first player to roll three sixes wins with a epic victory message.
- **🔄 Game Reset**: Easy to restart and play again.
- **📱 Responsive Design**: Works on desktop and mobile devices.

## 🚀 **How to Play**
1. **Enter Player Names**: All 4 players must input their names to start.
2. **Roll the Dice**: Click the "Roll Dice" button for your color.
3. **Hit a Six?**: Celebrate and click "Congratulations!" to get a random dare task.
4. **Win Condition**: Roll three sixes to become the champion!
5. **Enjoy the Fun**: Perform tasks, laugh, and keep playing!

## 🛠️ **Technologies Used**
- **React** ⚛️: For building the interactive UI.
- **Vite** ⚡: Fast development and build tool.
- **JavaScript (ES6+)**: Modern scripting for game logic.
- **CSS**: Stylish and responsive design.
- **HTML5**: Semantic markup.

## 📦 **Installation & Setup**
1. **Clone the Repository**:
   ```bash
   git clone <repository-url>
   cd ludo_game
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run the Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for Production**:
   ```bash
   npm run build
   ```
